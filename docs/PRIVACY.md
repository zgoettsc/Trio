# Privacy decisions for the algorithm-redesign work

Status: decided 2026-10-13 by the repository owner. This file is the record that
plan step S0.0 (`reports/Trio algorithm redesign implementation plan.md`) asks for.

## Repository visibility

`zgoettsc/Trio` is **public** (`gh api repos/zgoettsc/Trio` → `private: false`).
The owner has stated that they are comfortable with their own glucose, insulin,
sleep and heart-rate data being public. Therefore:

- The repository stays public.
- The two committed exports that contain personal data are **kept**:
  `docs/meal_export_7d_2026-05-14.json` (glucose, IOB, insulinReq, boluses,
  Garmin HR/HRV/sleep) and `docs/signal_export_7d_2026-04-16.json` (glucose,
  Garmin daily data). No history rewrite is performed.
- The `telemetry` branch (orphan branch written by the app) is also public. Its
  own README describes it as private; that statement is wrong and is superseded
  by this file. Audit on 2026-10-13: 479 files, daily folders from 2026-06-26
  onward containing `events.jsonl`, `loop.jsonl`, `summary.jsonl`, `meals.jsonl`,
  `garmin.jsonl` and `settings.json`; rows contain timestamps, glucose,
  insulin doses, meal-window state, Garmin sleep/HR/stress and the full
  basal/ISF/CR schedules. The owner accepts this.

## What this does NOT change

The plan's data-handling rules are kept for reasons other than secrecy:

- Raw 90-day loop traces and replay fixtures are **not committed** to this
  repository (size, churn, and keeping fixtures reproducible by hash). They live
  under `~/TrioLab/fixtures/` on the developer's Mac and are referenced from the
  repository only by SHA-256 in `AlgorithmKit/Fixtures/MANIFEST.json`.
- CI uses synthetic fixtures generated by the harness, never the owner's data,
  so a CI failure is never caused by a fixture that cannot be shared or
  regenerated.
- Any *other person* who builds this branch for themselves must make their own
  decision; the defaults in the app keep `telemetryEnabled` and
  `telemetryIncludeDosingTrace` **off**.

## If the decision changes

Steps to make the data private later are listed in plan step S0.0: make the
repository private, remove the two exports from history with
`git filter-repo --invert-paths`, purge or move the `telemetry` branch, and
rotate the PAT stored in the Keychain. All of these are the owner's actions.
